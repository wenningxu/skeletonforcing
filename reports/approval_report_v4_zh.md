# OF003 待审批：去除文本与同文本多状态的控制对照

2026-09-24。**已完成本地代码、真实参考动作的监督状态构造与CPU验证，尚未启动GPU。** 本报告同时列明两次从头训练的具体方案；两组都得到批准后才按顺序执行。前次OF002批准不覆盖本轮。

## 1. 是否应给控制点加噪

当前实验不支持直接断言“干净谷底没有作用”。时间场确实决定每一步哪些未知通道更新、更新多少；但OF002中，控制坐标对自由输出的影响很弱。**时间场的作用与模型是否利用控制值，是两个不同问题。** 尚未做同模型、同数据、同预算的统一时间场消融，所以不能据此否定谷底调度。

给已知坐标加噪、让其优先恢复，可以作为后续消融，但不是目前有证据的必要修复：

- 若控制目标本身也只以带噪值提供，会降低条件精度；即使提前恢复，也不自动保证周围动作跟随。
- 若另外始终提供干净目标，便是“带噪当前状态＋干净条件”的新设计，需要新增条件通路并明确监督；它不等同于目前固定谷底。
- 控制点有非零σ期间就失去“每一步控制值精确”的性质。最终可再投影到目标，但这种终点精确仍不能证明自由关节响应。
- OF002每条文本唯一对应一个固定动作，模型可以按文本记忆，再硬固定几个坐标。加噪不消除这一统计捷径。

按本次要求，**先做无文本与同文本多状态两组实验，保留控制XYZ全程σ=0**。不同时修改谷底、条件注入、损失和表示，否则无法判断改善来自哪项。若结果仍失败，再设计带噪锚点的单独对照。

无文本组移除模块后参数量下降，因此这不是参数量严格匹配的文本消融，而是按要求彻底移除文本条件的对照。共同运动模块在初始化时使用相同随机种子，检查其初始权重一致；训练批次、布局、时间步和初始噪声使用独立、相同种子的随机流，避免UMT5初始化消耗随机数造成混淆。

两组都使用多状态监督，所以两组之间能比较有无文本的效果；与OF002相比还改变了数据状态数和布局，不能仅凭新旧结果把提升严格归因于某一个变化。本轮不额外申请第三次旧基线重训。

## 3. 保留的模型条件

- 直接在266D运动特征空间训练，无动作编码器/VAE：root4、世界XYZ66、6D旋转126、局部速度66、接触4。
- 骨干宽度256、深度6、8头。观测mask只覆盖指定XYZ，不能泄漏该关节旋转/速度真值。
- 32步关节—时间场。`d=min(|t-ta|/20+graph_distance(j,ja)/2)`，`δ=0.75d/(1+d)`，未知量`σ=1-clamp((k/32-δ)/(1-δ),0,1)`；观测XYZ的σ恒为0。
- 训练抽取整条推理轨迹的全局离散k，不独立随机每个关节/帧的噪声等级。
- 前400步使用解析混合状态；之后50%真实模型rollout、50%解析状态，真实rollout最后最多4步保留梯度。
- 预测x0，以活跃未知通道的标准化MSE监督；另加0.01倍root/局部速度与位置一致性损失。尚未新增FK损失、IK求解、控制专用attention或运动学后处理。
- AdamW，lr2e-4，warm-up100步，weight decay0，梯度裁剪1，BF16，TF32允许。无EMA、文本dropout和结果驱动调参。

## 4. 有一致监督的多状态怎样构造

使用OF002已验证的八条真实训练参考片段：011936、002354、006468、013151、010807、014349、001294、004069；每条64帧。引用的是保存的**reference266真值**，不是上轮生成结果。

为每条动作构造5个状态，角度`α ∈ {−12°,−6°,0°,6°,12°}`。对HumanML3D表示中关节索引17的局部6D旋转，解出矩阵R后右乘局部Z轴旋转：

`R'(t)=R(t) @ Rz(α w(t))`

`w(t)=cos²(π(t−48)/24)`，仅在`|t−48|<12`生效，其余为0。变化在帧48达到峰值，在帧36和60降到0，时间包络及其一阶导数连续。

按上游FK的旋转定义，这一通道作用于进入关节17的骨段，实际支点是其父关节14，影响子链17/19/21。这里不把它误称为固定肩关节中心的完整解剖肩关节模型。

接着对**整套监督特征**进行一致更新：

1. 使用修改后的旋转、原root和骨长做FK，得到新XYZ。
2. 由新XYZ和原root朝向，重算局部线速度、root线速度与高度。
3. 保留未修改的旋转、root角速度与接触标签。脚部和root几何没有有意义的变化，脚接触标签不需因为右臂扰动重标。
4. 包络在末尾数帧为0；最后一个没有下一帧的速度沿用原值。

每条原caption在三个训练状态中完全相同。因此文本只能标识基本动作，无法独自确定右臂扰动；控制值必须提供额外信息。**不会把角度α、状态ID、干净整段动作或源动作ID传给模型**。

这些是保骨长、旋转/位置/速度自洽的合成运动状态，并非新采集的动作。没有做人体碰撞、肌肉动力学或完整解剖限位验证；小扰动保留原文本语义是本轮诊断假设，不应视为人工标注后的新数据集。

## 5. 训练/评价隔离与本地状态验证

- 训练：每条动作只用−12°、0°、+12°，共8×3=24状态。
- 插值评价：−6°、+6°，从不进入训练或归一化拟合。
- XYZ66维统计仅在24个训练状态拟合；其余200维沿用官方Mean/Std。
- 每轮把24状态打乱，每6个batch完整覆盖一次。随机种子1234；噪声发生器单独seed1235。
- 状态数据及metadata均绑定SHA256。模型输入不包含测试角度标签；评价中的角度只用于读取真值和记录结果。

本地检查实测：零扰动经FK重建与原XYZ最大差异约2.15e-6m；五种状态的FK—XYZ平均误差最大约3.78e-8m；平均骨长变化约8.5e-8m；重算局部速度的一致性残差为0。检查了保骨长、root/足部不变、接触保留、首尾还原及世界/局部速度范数一致。

所有布局中，同一动作不同状态的观察坐标向量最小距离约17.2mm；非观察右臂区域的真实变化RMS均至少5mm。这样避免“状态变化了、观察输入却不变”的不可辨识问题。

全部布局恰好观察三个关节—帧XYZ，且至少一个观察位于右臂扰动区域。这里有意修改了OF002的B/C布局，避免原B在帧28观察手腕、却完全看不到帧36以后才出现的变化。

| 布局 | 0-based `(帧,关节)` | 用途 |
|---|---|---|

| B | (8,7)、(44,21)、(52,0) | 训练与评价 |

## 7. 每组固定640次评价

8动作×5角度×4布局×4噪声种子=640例。基础seed2026–2029，第i条动作加10000×i。同一动作、布局和噪声下所有角度共享完全相同的初始噪声，先采样0°基线，再采样其他角度。

| 分组 | 数量/实验 | 用途 |
|---|---:|---|
| A/B/C + −12/0/+12° | 288 | 训练状态重建 |
| A/B/C + −6/+6° | 192 | 新状态插值 |
| D + −12/0/+12° | 96 | 新控制布局 |
| D + −6/+6° | 64 | 新布局与新状态同时出现 |

同文本组所有状态沿用该动作原caption；无文本组没有任何文本张量。本轮不增加错配文本实验，重点是控制值能否决定状态。

## 8. 成功标准：同时检验精确约束、重建和自由响应

### 每步约束

所有采样步骤检查观测通道逐位等于指定值；物理坐标目标误差在任何末端替换之前计算，门槛<1e-6m。非有限状态立即停止。

### 重建

沿用原门槛：未观测特征MSE<0.01；自由MPJPE<20mm；旋转/速度标准化MSE各<0.01；运动速度误差/静态基线<0.25；退化旋转0；FK—XYZ差异<对应真值底线+20mm。上表四个分组分别要求组内所有样本通过，并分别报告，不能合成一个“模型成功”掩盖失败。

### 与真实变化方向一致的控制响应

在帧36–60的关节17/19/21中，排除全部被钉住点，计算：

- `Δpred = generated(α) − generated(0)`
- `Δgt = target(α) − target(0)`
- `gain = <Δpred,Δgt> / ||Δgt||²`
- `relative_error = ||Δpred−Δgt|| / ||Δgt||`

理想值是gain=1、relative_error=0；只改观察点、其他位置不动时gain=0、relative_error=1。每例非零角度响应要求`0.5≤gain≤1.5`且`relative_error<0.5`；每个分组至少75%的非零角度例通过才标记响应诊断通过。仍报告完整分布、逐例失败、FK和骨长误差；这一阈值是诊断约定，不是通用动作质量标准。

此处有与移动控制相匹配的整段目标，所以能评价“是否正确跟随”，而不是仅要求周围产生任意变化。不能把0°到±6°的插值成功外推成任意关节任意轨迹控制，更不是动作类别泛化或流式实时性结果。

# OF003：无文本与同文本多状态实验结果

2026-09-24。两组均严格按已批准的 [v4 方案](approval_report_v4_zh.md) 各运行一次，完成 8,000 步训练和 640 例评价。**两组均未达到过拟合重建及正确控制响应门槛。** 没有追加训练、调参、重启或启动未批准的实验。Pod 已删除，证据已取回本地，两个 checkpoint 保留在私有网络卷。

## 1. 核心结果

以下重建均值包含每组全部 640 例；响应均值包含其中 512 例非零角度干预，始终排除被硬固定的坐标。

![四分组对比](../outputs/OF003-analysis/comparison.png)

无文本组确实受到控制值影响，但响应大多很弱或偏离正确变化：增益中位数仅 0.049，响应相对误差最低仍为 0.733；少数样本产生过大变化，把平均 RMS 拉高，最大达到 246.91 mm。不能把“变化更大”解释为“控制更好”。

同文本组更接近目标动作，但对同一文本下的状态变化几乎没有正确响应：增益范围 −0.03535～0.03087，响应相对误差范围 0.9830～1.0535。它没有通过“依赖控制值区分同一文本的不同状态”这一测试。

## 2. 运行的模型与训练数据

两组都使用直接动作空间的 266D 表示：root 4D、世界 XYZ 66D、旋转 126D、局部速度 66D、接触 4D。没有运动 VAE。位置替换自 HumanML3D 原生 263D 的 RIC 块，其他 200 个通道保留；世界坐标沿用原数据的规范化坐标系。

同一套 width=256、depth=6、heads=8 的关节—时间轴向 Transformer。无文本组删除文本投影与全部文本交叉注意力，9,628,429 参数，没有空文本或伪文本输入；同文本组使用官方 UMT5-XXL 的 4096D token 缓存，12,325,133 参数。同文本组每条源动作的所有状态使用完全相同的原始 caption。共同运动模块按相同随机种子初始化。

数据来自 8 条已验证的 HumanML3D 训练集动作，每条裁剪 64 帧。对局部旋转通道 17 做以第 48 帧为峰值、半径 12 帧的平滑局部旋转扰动，上游 FK 约定下 pivot 为 14，影响关节 17/19/21。随后重新计算 FK 世界位置、root 线速度/高度及局部速度，保留其余特征。训练状态为 −12°/0°/+12°，共 24 段；−6°/+6°仅用于评价，不参与训练或统计量拟合。没有角度标签、状态编号或 clip ID 输入网络。

这是具有运动学一致性的人工状态扩充；并未验证碰撞、动力学或解剖角度限制，沿用 caption 也不等于通过了语义评审。评价中的真值 FK 底线最大约 8.13×10⁻⁸ m，故本次较大的 FK—XYZ 差异不能用原始数据转换底线解释。

每组 batch=4、AdamW、学习率 2×10⁻⁴、100 步 warmup、8,000 步。先 400 步 teacher state，其后 50% 使用模型生成的 rollout 状态，最后至多 4 步保留梯度；目标为 x0 重建及 0.01 权重的一致性项。完整 joint×time 场直接取自相同 32 步推理轨迹，未改成逐关节随机时间。所有控制位置在训练与采样各步均保持 σ=0。

两组已记录的全部训练条目，其 batch、布局、全局步索引 k 和 rollout 分支逐项一致。文本条件及对应模块存在差别，参数量也不同；本次不是等参数量架构比较。单个训练随机种子、四个评价噪声种子不足以估计训练重复间的不确定性。

## 4. 精确约束与一致性分开看

所有 1,280 例的初始化及各采样步骤都检查了归一化观测通道逐位相等，且所有状态有限。物理单位下的锚点误差直接与原始目标比较，没有末端二次覆盖来隐藏误差。上述微小差异来自浮点归一化往返，所有例均低于 10⁻⁶ m。

但是，精确约束没有自动保证其余表示一致：

预测 root 线速度与显式 XYZ 重算值的平均差异分别为 9.01 和 6.53 mm/frame；局部速度差异为 6.21 和 4.70 mm/frame；root 高度差异为 6.70 和 4.93 mm。没有用导出时重算速度去替换原模型输出、掩盖这些差异。

## 5. 对“谷底是否应加噪”的判断

本次可以区分三件事：

1. **锚点值有没有影响自由生成？** 有。无文本组自由坐标的成对输出发生变化，因此不能说控制完全没有进入网络。
2. **是否学到了正确的协调变化？** 没有。即使训练数据给出了相同 caption 下的多个一致监督状态，两组仍未通过正确响应指标；同文本组尤其接近忽略状态变化。
3. **谷底时间场比其他时间场是否更有效？** 本次无法回答。两组都用同一个谷底调度，没有 uniform/noisy-anchor 对照。控制值敏感性也不能直接归因于谷底时间场。

所以，本次没有证据支持“必须给控制点加噪才能学会控制”，也没有证据证明当前无噪谷底方案有效。若给生成状态里的控制点加入噪声，这些坐标在中间步骤就不再满足 σ=0/精确固定；若每步立刻投影回真值，实际又恢复成无噪锚点。可将“干净控制条件”和“带噪生成状态”设计为两条独立输入路径，但那是另一种明确的模型方案，需要重新报告和审批。

当前证据支持优先检查条件利用与训练目标：稀疏控制的局部状态差异占整体重建损失很少，文本提供的动作身份仍能使模型获得较低平均损失。这个解释与结果相容，但不是已经排除了优化不足、条件传递结构或训练/采样数值差异的因果结论。下一次实验应先用单条动作的多状态任务验证自由邻域可辨识响应，再把条件注入、局部配对监督和时间场消融分开，避免同时修改多项后无法归因。本次未执行这些新实验。

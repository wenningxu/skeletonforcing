# OF009：默认从第一帧 root 出发的无控制山谷生成

2026-09-26。按用户最新澄清：**与原山谷时间场是同一个逻辑，仅把默认传播入口固定为第0帧、关节0（root）**。本文件取代此前整段root分层生成和另设重叠分层窗口的草案；那些日程不会用于实验。

## 时间场的精确定义

直接调用现有 `schedule.distance_field` 和 `schedule.noise_levels`，不重新设计一套波前公式。入口掩码仅在 `(frame=0, joint=0)` 为true，用于计算距离；观测掩码始终全部为false。

对帧f、关节j，沿用原默认参数：

`D(f,j) = f/20 + graph_distance(root,j)/2`

`delay(f,j) = 0.75 * D(f,j)/(1+D(f,j))`

`sigma(p,f,j) = 1 - clamp((p-delay(f,j))/(1-delay(f,j)), 0, 1)`

其中 `p=k/32`，完整采样格点为 `k=0…32`。噪声降低先从第一帧root开始，同时沿时间轴和骨骼链向外推进。距离更远的关节帧稍后开始；已经开始的区域继续去噪，波前彼此重叠。后续帧的root也有时间距离，不会与第一帧root同时提前生成。

本轮严格保留原公式的一个性质：**所有区域都在p=1结束去噪**。root先开始、在中途更干净，但不提前锁死；这不是“root全部完成后，再轮到下一层”。水波描述的是这种关节—帧二维噪声场传播，不表示使用真实水波方程。

图中横轴是动作帧，纵轴是骨骼深度；不同面板是同一次去噪过程的不同步骤。真正模型时间场覆盖全部22个关节及其特征，图仅按相同深度合并展示。

## 默认入口不是已知 root 条件

本轮不提供任何GT root、位置、旋转、速度、朝向或起始姿态。全部266D在初始时都是归一化高斯噪声，包含第一帧root。第0帧root仅因为距离为0而最先降低sigma；不能在没有给定运动值时，把它伪装成已知无噪声控制点。

代码分离“用于计算距离的入口”与“已知通道mask”：前者有一个true，后者始终全false。没有位置回填，没有控制损失，也不报告锚点成功率。每次推理读取模型上一步生成的状态。

## 网络与动作表示

回到已标准化 `wan_joint_time_v1`，不使用上一轮Kimodo适配：1024宽、8层、8头、FFN2048，78,053,389参数。保留Wan自注意力、Q/K RMSNorm、三轴RoPE、FFN和调制输出头。暂时无文本、无动作VAE。

动作表示为root4 + world XYZ66 + local rot6d126 + local velocity66 + contact4。root的4D特征、pelvis XYZ与root局部速度属于关节0；其它关节的位置、旋转和速度属于该关节；接触跟随对应足关节。因此同一关节同一帧的这些冗余通道使用相同sigma，不把未观测旋转/速度设成已知值。

完整逐通道sigma经正弦编码和时间MLP注入逐token、逐层的shift/scale/gate（AdaLN调制），不直接乘隐藏特征、不平均关节/帧sigma。已知mask投影保留原网络参数布局，但本轮输入恒为零。

注意力仍能访问整个64帧窗口。这是时间场引导的生成次序，不是已实现的因果注意力或实时流式生成；本轮不声称流式延迟结果。

## 训练严格匹配推理时间场

每32次训练打乱并遍历全部32个完整推理格点。每次只选一个全局k，整张关节—帧时间场由同一山谷函数产生；不独立随机采样每个关节/帧的噪声级别。CPU测试逐格点对比原山谷实现，要求逐元素相等。

前400步用解析teacher状态 `(1-sigma)*x0 + sigma*epsilon`；之后50%训练批次从噪声实际rollout到该格点，读取模型产生的状态，前缀截断、最后最多4步保留梯度。teacher分支包含GT混合信息；全部最终评估和rollout分支都不以GT替换任何运动通道。测试验证同一模型和噪声下改变GT不会改变rollout状态。

主损失为当前sigma下降通道的归一化x0 MSE，适用于偏离解析轨迹的实际rollout状态，不使用失真的原始epsilon-x速度标签。附加0.01 root/速度一致性损失，按当前活动通道筛选，并以真实状态保留非活动通道。

时间波前额外要求：速度一致性只有在当前帧和下一帧的相关位置都已开始生成、所需root朝向前缀可用时计算。否则它会错误地要求当前预测速度匹配下一帧尚未触及的高斯噪声。位置和速度的直接x0监督仍保留；没有删掉速度特征。旋转/FK一致性单独评估，不声称由这个损失保证。

更新为 `x_next=(sigma_next/sigma)*x + (1-sigma_next/sigma)*x0_pred`，只修改sigma下降的通道。未开始去噪的区域保持其原噪声；最终sigma_next=0时直接提交模型预测。不存在GT回填。

## 首轮小样本配置

只使用已有已验证状态库中动作011936的64帧、0°状态；不使用其±角度变体或其它动作。0°状态沿用已建立库的FK/速度一致化流程，不声称与原始263D逐字节相同。数据/元数据哈希继续校验。

XYZ统计仅由这一训练状态拟合，标准差下限0.05；其余200通道复用官方HumanML3D统计。该过拟合归一化含训练统计先验，但不提供逐帧GT root；它不能直接替代全数据基准的训练集统计。

拟议一次从随机初始化开始的4,000步训练：batch3为同一动作搭配三个独立噪声；AdamW lr=2e-4、betas=(0.9,0.99)、eps=1e-8、weight decay=0、100步预热、梯度裁剪1；FP32参数、BF16 autocast，训练seed1234、噪声seed1235。32步采样，完整格点覆盖次数保存到证据中。

## 评估与判断范围

用2026–2033八个未用于训练的固定seed从纯噪声生成；无GT条件、无teacher。保存k=0/4/8/12/16/20/24/28/32的实际状态、噪声和最终266D输出。中间状态刻意含尚未生成的噪声，不把其全局误差当作最终重建质量。

最终报告全局、root、骨骼深度和时间段的XYZ误差，归一化特征/旋转/速度误差，FK与XYZ不一致，骨长误差，root/速度一致性，以及时间变化幅度。检查每次更新未活动通道逐位不变。

八个seed均须满足：特征MSE<0.01、XYZ MPJPE<20mm、归一化旋转/速度MSE各<0.01、运动速度误差/静止预测误差<0.25、无退化旋转、FK不一致小于GT底噪+20mm；时间变化RMS/GT∈[0.8,1.2]。不使用控制响应或锚点门槛。

这是单动作过拟合，只回答无条件顺序生成链路能否学会该运动。没有本轮均匀日程对照，因此不能声称山谷时间场有优势；不同seed收敛到同一训练动作也不能当作多样性测试。OF006/OF008的条件、训练状态数不同，不作严格横向因果比较。未安排正式FID、文本匹配、BABEL、全数据或流式延迟实验。

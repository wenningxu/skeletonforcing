# OF002-v3 待审批：八动作过拟合与条件响应诊断

2026-09-23。**当前只完成本地代码与 CPU 测试，未启动新的 GPU。** 本报告申请一轮独立实验；此前 OF001 的批准不延续到本轮。

## 1. 目的与已有证据

OF001 使用真实 HumanML3D、266D 冗余表示、官方 UMT5，完成 2000 步单动作过拟合。四个新噪声种子下自由关节 MPJPE 均值 7.44 mm，控制点全程精确不变，旋转 FK 与显式位置平均仍相差 14.07 mm。

单动作模型可能完全忽略文本和控制，仅靠帧索引记住动作。因此本轮依次回答：

1. 同一模型能否记住八条不同动作，而非输出一个平均动作？
2. 对同一动作，三种训练过的控制布局能否稳定重建？换成未训练的控制布局是否仍能重建？
3. 固定噪声和控制点，换错文本或空文本后，输出是否变化、重建是否退化？
4. 固定噪声和文本，仅将一个手腕目标平移 ±10 cm，模型是否调整未被钉住的邻近关节，还是只靠最后的硬拷贝命中目标？

这是扩大后的实现诊断，不是正式 HumanML3D/BABEL benchmark，不评判 SOTA，不证明谷底调度优于其他调度。

## 2. 模型与表示：哪些保持，哪些改变

沿用 OF001 的模型和监督定义：

| 项目 | 方案 |
|---|---|
| 动作表示 | root 4 + 显式全局 XYZ 66 + 6D 旋转 126 + 局部速度 66 + 接触 4，共 266D |
| 保留的原表示 | 原 HumanML3D 263D 中除 RIC 位置外的 200 个通道逐值保留 |
| 动作编码器 | 无；直接在动作特征空间训练和采样 |
| 文本编码器 | FloodDiffusion 官方冻结 UMT5-XXL，官方 tokenizer/权重，4096D token，不做均值池化 |
| 骨干 | 关节和时间交替注意力，token 级文本交叉注意力，宽度256、深度6、8头，12,325,133参数 |
| 输出 | 预测干净动作 x0；解析状态和模型 rollout 状态都监督到该目标 |
| 额外损失 | 0.01 × root 高度、root 线速度、局部速度与显式位置的一致性损失 |
| 尚未强制的约束 | 旋转 FK 与位置严格一致、固定骨长、接触和碰撞均没有硬求解器 |

本轮从随机初始化训练，不恢复 OF001 的单动作权重。改变的是训练动作数、批量、控制布局和训练步数，以及对应评测矩阵。模型骨干、损失权重、去噪步数保持一致。

归一化继续使用官方 Mean/Std 的 200 个保留通道。新增的 66 个全局位置通道只在选定八条训练片段上拟合均值/标准差，标准差下限 0.05 m。该统计量仅用于小样本过拟合，不能当作全量模型的统计量。

## 3. 输入的具体含义

每个关节—帧 token 打包该关节所属的特征，最多13维，padding 通道屏蔽：

- 当前状态：带噪或已去噪的动作特征；推理每步使用上一步生成状态。
- 逐通道 σ：告知该特征在当前时间场中的噪声水平，不是额外的运动目标。
- 逐通道观察 mask：区分外部指定的精确 XYZ 与未知旋转、速度等。只控制位置时不会把该关节的所有通道都当成已知。
- 关节索引嵌入：标识对应哪个骨架关节；帧索引 Fourier 编码：标识64帧窗口中的位置。二者都是结构信息，不包含动作真值。
- UMT5 token：通过交叉注意力提供文本条件。

控制值只出现在观察 mask 对应的 XYZ 通道。测试已验证：任意改写非观察真值通道，不会改变传入模型的控制张量。

## 4. 时间场与 rollout

距离为 `d=min_anchor(|t-ta|/20 + skeleton_graph_distance(j,ja)/2)`；延迟 `δ=0.75d/(1+d)`。全局进度 `p=k/32` 时，未知通道 `σ=1-clamp((p-δ)/(1-δ),0,1)`；已知 XYZ 的 σ 始终为0。

所有未知量从纯噪声 σ=1 开始，近谷底先去噪，远处后开始，终点均为0。控制点的未知旋转/速度依然从噪声开始，不能因其位置被指定就读取旋转/速度真值。

训练只随机选完整轨迹的离散索引 k，**不独立随机生成各帧或关节的噪声等级**。三种控制布局都通过同一 `field_step` 构造训练和推理时间场。每个训练 batch 使用一种布局和同一全局步 k，但有不同动作与独立噪声。

- 前400步：解析数据—噪声混合状态，用于启动训练。
- 后续步骤：以50%概率从噪声实际 rollout 到第k步，另一半使用解析状态。
- 实际 rollout 的前缀无梯度，最后至多4步保留梯度；仍监督干净动作，不把原始 epsilon-x0 当成偏离解析路径后的正确速度标签。
- 推理完整执行32步，每步检查控制值精确不变和状态有限。

## 5. 数据抽样与隔离

复用网络卷中已核验的官方资产，revision 为 `97fe404e1b52293b6c8db47619fa7ab9b5459405`。本轮不下载 BABEL，不加载预训练动作生成器。

八条动作按以下固定算法选择，不看训练效果挑数据：

1. 要求 train/val/test 三个官方划分文件都存在，并检查去除镜像前缀后的动作 ID 无交集。
2. 从 train 的去重、排序 ID 出发，排除 `M` 镜像样本及 OF001 的 `000002`，用 seed31415 打乱候选顺序。
3. 接受有限的263D序列，原长64–200帧，固定取前64帧；只取覆盖完整动作的 caption，按文件顺序选择第一个尚未用过的非空描述。
4. 选中片段的平均 XYZ 速度需至少0.002 m/frame，避免近静止样本使速度基线失效。
5. 与此前选中片段的逐帧 XYZ 平均距离需至少0.1 m，减少重复轨迹；这一准则不是动作类别均衡或语义多样性的证明。
6. 接受前八条。若不足八条就停止，不改用验证/测试集。记录所有选中 ID、caption、源文件哈希与拒绝原因计数。

具体八个 ID 将在挂载数据后、训练前按上述算法生成并写入 selection.json；目前本地没有完整动作数据，不能提前伪造 ID。测试文本和新布局评测仍基于这八条训练动作，**不是未见动作泛化测试**。

## 6. 控制布局

以下索引均从0开始，每个样本恰好指定三个关节—帧 XYZ。

| 布局 | 三个控制点 `(帧,关节)` | 用途 |
|---|---|---|
| A | (16,0/root)、(32,20/左手腕)、(48,21/右手腕) | 训练与评价 |
| B | (8,7/左脚踝)、(28,21/右手腕)、(52,0/root) | 训练与评价 |
| C | (12,20/左手腕)、(36,8/右脚踝)、(56,15/头部) | 训练与评价 |
| D | (10,0/root)、(30,18/左肘)、(50,19/右肘) | 仅评价，训练不出现 |

训练中 A/B/C 均匀抽样；观测坐标始终来自当前训练动作。D 是一个预先规定的未见布局；成功仍不等于任意布局泛化。

## 7. 一次训练的固定设置

| 项目 | 设置 |
|---|---|
| clips / frames / batch | 8 / 64 / 4 |
| 批次采样 | 每轮打乱8条动作，每2步覆盖一次，不重复或丢弃样本 |
| 最大训练步数 | 8000，不按结果追加 |

| 随机种子 | 训练1234；数据选择31415 |
| 精度 | BF16 autocast、TF32允许 |
| 禁用 | EMA、文本dropout、随机裁剪、空间增强、学习率结果驱动调整 |

固定8000步是预先选择的诊断预算，不保证必然过拟合成功。门槛未过时保留失败，下一轮另行论证，不延长本轮。

## 8. 配对评测矩阵：共256次完整采样

噪声基础种子2026–2029；第i条动作使用 `seed+i*10000`。同一动作和种子的所有条件复用**同一初始噪声**，评价不更新权重。

| 条件 | 数量 | 比较对象 |
|---|---:|---|
| 正确文本，A/B/C | 8×4×3 =96 | 各自动作真值，训练布局重建 |
| 正确文本，D | 8×4 =32 | 各自动作真值，未见布局重建 |
| A，错配文本 | 32 | caption 按所选顺序循环错配到下一条；控制保持原动作 |
| A，空文本 | 32 | 空字符串也由同一个真实 UMT5 编码，不用零向量冒充 |
| A，右手腕X目标−0.1m | 32 | 同噪声、同文本的原始A输出 |
| A，右手腕X目标+0.1m | 32 | 同噪声、同文本的原始A输出 |

只改变帧48右手腕的一个世界X坐标，其他控制值不变；不移动 root 或整段真值。移动后的条件没有真实对应动作，因此不会把“离原始动作更远”当作更差生成质量。

## 9. 判定标准与可解释的失败

### 9.1 重建门槛

沿用 OF001 的逐样本门槛：未观测特征 MSE<0.01；自由关节 MPJPE<20mm；控制最大误差<1e-6m；旋转/速度标准化 MSE各<0.01；动作速度误差/静态基线误差<0.25；退化旋转数0；FK—XYZ平均差异低于该真值底线+20mm。

96个训练布局样本必须全部满足才标记训练布局过拟合通过。32个D布局样本单独要求全部满足。所有逐动作逐种子结果保留，不能只看均值。步数不足或评价未完成不算通过。

### 9.2 文本诊断

分别报告正确、错配、空文本的自由关节误差，以及相对于正确文本输出的未控制关节变化。文本与三个动作控制点可能冲突，所以“错配文本误差上升”仅说明条件依赖，不等于语义理解能力；差异很小也可能是控制条件占主导。

本轮不为语义有效性编造强阈值，不用八条训练动作计算正式 R-Precision。若文本诊断无法区分，后续需专门设计更弱运动约束或无运动控制的文本辨别实验，经单独审批。

### 9.3 控制响应诊断

对移动目标的64次采样报告：

- 指定目标误差（物理坐标末端替换之前），每一步归一化控制值是否精确相等。
- 全部非控制关节的平均位移变化。
- 帧44–52中右手腕及其父关节右肘，排除被钉住点后的平均位移变化。
- 上述邻域沿干预轴的有符号增益：平均X变化/目标X变化，观察响应方向。
- 二阶帧差分变化、骨长误差、FK—XYZ差异、root/速度一致性；这些属于诊断，并非完整物理可行性判据。

还构建纯覆盖基线：取原A输出，只替换移动后的目标值。该基线控制误差也是零，但自由关节变化为零。测试已确保它不会通过响应检查。

预先规定一个**较弱的非零响应门槛**：至少75%的移动目标样本，其非控制邻域平均变化≥2mm。它用于排除“只钉控制点、其余完全不动”，不保证动作合理；有响应但骨长/旋转严重恶化同样不能进入正式实验。报告不会把这一启发式阈值包装成公认benchmark。

# OF009 修正版：相同局部去噪步数、错峰完成的山谷时间场

2026-09-26。用户指出“所有关节应该有相同的去噪步数”。该要求取代v10中的“所有位置最后同时归零”。本轮仅修改本地方案、代码及动图，尚未创建GPU。

## 原日程的问题与修正

原日程把所有位置的结束时刻压到同一个全局终点。入口root从第一步去噪，远处关节帧晚开始却必须同时结束，因此它们的有效更新次数和每步sigma变化都不相同。之前动图忠实呈现了这个旧实现，但该实现不满足新的等步数要求。

修正为：**相同局部曲线沿关节—帧距离平移，只改变开始时刻，不缩短远处的去噪过程。** 保留第0帧root入口，以及沿时间和骨骼链传播的距离定义：

`D(f,j) = f/20 + graph_distance(root,j)/2`

`start(f,j) = ceil(32 * 0.75 * D/(1+D))`

对离散边界仅使用1e-6容差，防止数值误差把理论整数推到下一步。32是传播延迟的参考尺度；它与下面的局部去噪步数是独立参数，本轮二者均取32。

`local_index(k,f,j) = clamp(k - start(f,j), 0, 32)`

`sigma(k,f,j) = 1 - local_index(k,f,j)/32`

每个关节帧都严格走过 `1, 31/32, 30/32, …, 1/32, 0`，恰好32次sigma下降、每次下降1/32。晚到的波前不会加速收尾。开始前保持原噪声，完成后保持模型生成值。

| 关节帧 | 开始全局步 | 结束全局步 | 有效更新数 |
|---|---:|---:|---:|
| 第0帧root | 0 | 32 | 32 |
| 第0帧手腕（关节21） | 19 | 51 | 32 |
| 第63帧手腕（关节21） | 21 | 53 | 32 |

本64帧窗口总共53次全局网络调用、54个保存状态（含初始状态）。每个关节帧只有32次状态更新；已经完成的token仍作为上下文参与后续网络注意力，不能把32次局部更新误称为只有32次网络计算。

开始时刻按整数步离散化，距离接近的位置可能同一轮启动，但仍保留22个独立关节token/帧。父关节或较早帧的sigma不高于其后继，传播方向不变。此实现保留旧距离与延迟映射，**不再与旧sigma曲线逐元素一致**。

## 无控制、模型和表示

入口只是日程坐标，不是真实观测。初始266D全部为归一化高斯噪声，包括入口root；known mask始终全false，无GT root、位置、旋转、速度、朝向或caption条件。推理每一步读取模型上一步产生的状态；sigma=0的已完成值也由模型生成，后续保持不变。

继续采用标准化Wan `wan_joint_time_v1`：1024宽、8层、8头、FFN2048，78,053,389参数；Q/K RMSNorm、三轴RoPE、完整关节—帧注意力、逐token逐层AdaLN shift/scale/gate、调制输出头。没有Kimodo骨干、文本编码器或动作VAE。

266D保持root4、world XYZ66、local rot6d126、local velocity66、contact4；每个通道跟随所属关节帧的局部曲线，接触跟随足关节。已知mask分支保留参数布局但输入恒为零。sigma正弦编码经时间MLP进入每层调制，不直接乘隐藏特征，也不平均关节和帧sigma。

## 训练与采样

完整53步时间场由同一实现生成；每53次训练打乱并遍历这53个全局格点，不独立随机采样各关节/帧时间。4,000步训练不能被53整除，所以保存实际格点覆盖次数供复核。

前400步使用解析teacher状态 `(1-sigma)*x0 + sigma*epsilon`；之后50%概率使用实际模型rollout状态，截断前缀、保留最后最多4步梯度。teacher分支的已完成位置是GT；rollout分支及全部推理中的已完成位置来自模型。测试明确检查改变GT不会改变rollout状态，以及已完成root不会被后续输出覆盖。

主损失是当前活动通道的归一化x0 MSE，加0.01活动root/速度一致性损失。速度一致性要求所依赖的相邻帧位置和root朝向前缀已开始生成，避免把未触及的高斯噪声当作物理目标。位置/旋转/速度的直接监督保留，FK与XYZ一致性另行报告。相同采样更新数不等于相同训练梯度权重；当前仍采用每批活动通道平均MSE，未加入新的损失重加权。

采样更新为 `x_next=(sigma_next/sigma)*x + (1-sigma_next/sigma)*x0_pred`，仅更新sigma下降的通道。未开始与已完成区域逐位保持不变。有限窗口内仍是完整注意力，本轮不声称已实现因果流式系统。

## 拟议小样本实验及门槛

一次从随机初始化训练：动作011936、64帧、现有已验证状态库的0°状态；不加入控制变体。该状态保留状态库既有的FK/速度一致化处理，不声称与原始263D逐字节一致。XYZ统计仅由该训练状态拟合（std下限0.05），其它200通道使用官方HumanML3D统计；这是过拟合统计，不适用于直接宣称全数据成绩。

4,000步，batch3是同一动作与三个独立噪声；AdamW lr2e-4、betas(0.9,0.99)、eps1e-8、weight decay0、100步预热、梯度裁剪1；FP32参数/BF16 autocast，训练seed1234、噪声seed1235。

以2026–2033八个未用于训练的seed，从纯噪声无条件生成。保存全局步0/8/16/24/32/40/48/53状态；最终按root、骨骼深度及时间块报告误差。八例都须达到：特征MSE<0.01、XYZ MPJPE<20mm、归一化旋转/速度MSE各<0.01、速度误差/静止预测误差<0.25、无退化旋转、FK不一致<GT底噪+20mm、时间变化RMS/GT∈[0.8,1.2]。不报告控制响应或锚点满足率。

本轮只是单动作过拟合，无均匀时间场对照、FID、文本匹配、BABEL或正式流式延迟结果。不能把更新次数一致或CPU测试通过当作模型质量改善。
